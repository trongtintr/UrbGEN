<h1 align="center">UrbGEN</h1>

<p align="center">
  A generative urban design tool for Grasshopper/Rhino that automatically
  generates building configurations under urban planning constraints.
</p>

---

## Demo

![UrbGEN generated massing on an urban context](images/UrbGEN-example.gif)

*Generated massing across multiple sites, coloured by building height.*

## Features

- Building Coverage Ratio (BCR)
- Floor Area Ratio (FAR)
- Building height
- Setbacks
- Building orientation
- Multiple building typologies
- Parametric urban massing generation

## Workflow

The component takes a site curve and planning targets as input, and returns
tower/podium geometry together with the achieved BCR, FAR, GFA and height metrics.

![UrbGEN Grasshopper definition](images/UrbGEN-workflow.png)

## Installation

Install UrbGEN through the Rhino Package Manager or Yak package manager.
